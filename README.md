# ReCompressProgram

圧縮ファイルを一度解凍し、ZIPファイルへ再圧縮するGUIアプリです。

## 使い方

```powershell
python -m pip install -r requirements.txt
python app.py
```

画面にファイルまたはフォルダを追加して、`再圧縮開始` を押します。`tkinterdnd2` をインストールしている場合は、ファイルやフォルダのドラッグアンドドロップでも追加できます。

`zipファイルを対象外にする` にチェックを入れると、`.zip` は処理対象から外します。

## 画像分割オプション

`横長画像を中央で左右に分割する` にチェックを入れると、解凍後、ZIPへ再圧縮する前に画像ファイルを確認します。画像の横幅が縦幅より長い場合は中央で左右に分割し、分割前の画像はZIPに入れません。分割しなかった画像はそのまま保持します。

分割後のファイル名順は、画面上で次のどちらかを選択できます。

- `右側→左側`: `元ファイル名_001.ext` が右側、`元ファイル名_002.ext` が左側
- `左側→右側`: `元ファイル名_001.ext` が左側、`元ファイル名_002.ext` が右側

## 対応形式

- 標準対応: `.zip`, `.tar`, `.tar.gz`, `.tgz`, `.tar.bz2`, `.tbz2`, `.tar.xz`, `.txz`, `.gz`, `.bz2`, `.xz`
- 7-Zipがインストールされている場合: `.rar`, `.7z`, `.cab`, `.iso`, `.arj`, `.lzh`

RARファイルの解凍には7-Zipを使用します。7-ZipがPATHに無い場合でも、標準のインストール先である `C:\Program Files\7-Zip\7z.exe` を自動検出します。

出力先は元ファイルと同じフォルダです。再圧縮が成功した場合、元の圧縮ファイルは同じフォルダ内の `before` フォルダへ移動します。

再圧縮後のZIPファイル名は、元の圧縮ファイル名に対応した名前になります。元ファイルが `.zip` の場合は同じファイル名で保存されますが、先に元ファイルを `before` へ移動してから最終配置するため、元ファイルを直接上書きしません。`.tar.gz` などの場合は、元の拡張子を `.zip` に置き換えた名前で保存します。

一覧には圧縮ファイル内の横長画像数を表示します。行を右クリックすると、圧縮ファイル内で最初に見つかった画像をプレビューします。
